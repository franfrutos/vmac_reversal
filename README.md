# Explicit knowledge modulates Pavlovian attentional biases

This project is the repository for the data, scripts, and materials used for the manuscript entitled: "*Explicit knowledge modulates Pavlovian attentional biases*".

### Project Structure ###

The project is organized into the following main sections:

- **Input**: Stores the raw data files used in the main analyses and re-analyses.
- **Output**: Stores the files generated by code, including cached analysis objects, model outputs, figures, and manuscript render files. 
- **Scripts**: Includes the R scripts used to load and preprocess data, run the main analyses, fit the computational models, and generate manuscript figures.
- **Models**: Contains the Stan model files used for the Bayesian computational models. 
- **vmac_reversal_manuscript.qmd**: The Quarto manuscript source file.
- **run_all.R**: Main project runner for the core analyses.

### Output Folder Structure ###

The **output** folder is organized as follows:

- **output/analysis**: Cached `.rds` objects used by the manuscript.
- **output/models**: Computational modelling outputs and related files.
- **output/figures**: Figures generated by the analysis scripts.
- **output/manuscript**: Files generated when rendering the Quarto manuscript.

### Scripts Folder Structure ###

The **scripts** folder is organized as follows:

- *analysis_e1.R*: Main analysis script for the **Results** section of *Experiment 1*.
- *analysis_e2.R*: Main analysis script for the **Results** section of *Experiment 2*.
- *re_analysis_Le2024.R*: Re-analysis of the reversal procedure reported in *Le et al. (2024)*.
- *run_model_comparison.R*: Bayesian model comparison script for the model-free and model-based reversal learning accounts.
- *posterior_predictions.R*: Script used to generate the posterior predictive figure reported in the manuscript.
- *power.R*: Script for the project power analysis output.
- *load_data.R*: Loads and preprocesses the main behavioral data used by `analysis_e1.R` and `analysis_e2.R`.
- *functions.R*: Loads helper functions used across `analysis_e1.R` and `analysis_e2.R` analyses and manuscript reporting.
- *model_load_data.R*: Loads and preprocesses the data used by the Bayesian model comparison.
- *model_functions.R*: Helper functions used by the Bayesian post-processing and plotting scripts.

### Typical Workflow ###

The project can be run from `run_all.R`, which runs the relevant analysis scripts.

The manuscript is then rendered from `vmac_reversal_manuscript.qmd` using the `apaquarto` extension.
