# Explicit knowledge modulates Pavlovian attentional biases

This repository contains all the data, R code, Stan models, and supplementary materials associated with the paper: **"Explicit knowledge modulates Pavlovian attentional biases"**.

> **Note:** All the results used by the manuscript (cached analysis objects, model outputs, and figures) are included in the `output` folder, so the manuscript and the Supplementary Material can be rendered without running the analyses again.

---

## 📂 Repository Structure

The directory is organized as follows:

### 1. Input
Contains the datasets used across the analyses.
* **1.1 Experiments 1, 2a, and 2b**: Trial-level data (`data_e1.csv` and `data_e2.csv`) and demographic data of the participants (`descriptive_e1.csv` and `descriptive_e2.csv`).
* **1.2 Le et al. (2025)**: Data from Experiment 2 of Le et al. (2025), obtained from their public repository (`df_le2.csv` and `summary_Le.csv`), used for the re-analysis and the computational models.

### 2. Manuscript
Source files of the manuscript, its preprint version, and the Supplementary Material.
* **2.1 vmac_reversal_manuscript.qmd**: Quarto source file of the manuscript.
* **2.2 vmac_reversal_preprint.qmd**: Preprint version of the manuscript in journal (two-column) format, which takes the text from `vmac_reversal_manuscript.qmd`.
* **2.3 vmac_reversal_supplementary.qmd**: Quarto source file of the Supplementary Material.
* **2.4 refs.bib**: References of all documents.
* **2.5 _extensions**: Quarto extensions used to render the documents (`apaquarto` and `quarto-wordcount`).

### 3. Models
The source code for the Bayesian models.
* **3.1 model_free_rev.stan and model_based_rev.stan**: Model-free and model-based reversal learning models fitted to the data of Le et al. (2025).
* **3.2 recovery**: The same models without posterior predictions, used for the model recovery.

### 4. Output
Results generated by the scripts.
* **4.1 analysis**: Cached `.rds` objects of the analyses of Experiments 1, 2a, and 2b and of the re-analysis of Le et al. (2025), used by the manuscript.
* **4.2 models**: Results of the Bayesian model comparison and posterior predictive checks.
    * *recovery*: Results of the model recovery (Supplementary Material). The `checkpoints` subfolder contains the simulated dataset of each fit.
* **4.3 figures**: All figures of the manuscript and the Supplementary Material. Figure 1, which shows the task, is a static image.
* **4.4 manuscript**: Rendered manuscript, preprint, and Supplementary Material.

### 5. Scripts
The complete codebase for reproducing the entire study.
* **5.1 Data loading**: `load_data.R` loads and preprocesses the behavioral data, and `model_load_data.R` the data used by the computational models.
* **5.2 Behavioral analyses**:
    * *analysis_e1.R*: Analyses of Experiment 1.
    * *analysis_e2.R*: Analyses of Experiments 2a and 2b.
    * *re_analysis_Le2024.R*: Re-analysis of the reversal procedure reported in Le et al. (2025).
    * *power.R*: Simulation-based power analysis for Experiments 2a and 2b (Supplementary Material).
* **5.3 Computational modeling**:
    * *run_model_comparison.R*: Bayesian model comparison of the model-free and model-based reversal learning accounts.
    * *posterior_predictions.R*: Posterior predictive checks reported in the manuscript.
    * *model_recovery.R*: Model recovery for the model-free and model-based accounts (Supplementary Material).
    * *setup_model_recovery.R*: Installs the R packages and the CmdStan version needed to run `model_recovery.R` on a new machine.
* **5.4 R functions**: Helper functions used by the behavioral analyses and manuscript reporting (`functions.R`) and by the computational modeling (`model_functions.R`).
* **5.5 Rendering**: Quarto filters that add the word count to the title page (`wordcount_titlepage.lua`) and set the figures of the preprint (`preprint.lua`), and post-render step that moves the auxiliary render files to `output/manuscript` (`post_render_cleanup.cmd`). Two more filters are in the root folder: `fig.lua` allows short captions for figures with subfigures, and `supplement-title.lua` adds the heading of the Supplementary Material to its title page.

### 6. Materials

The original jsPsych tasks, as they were run on the JATOS server of the University of Granada. Each folder has its own README with instructions to run the task, its settings, and the data it records.

* **6.1 experiment1**: Task of Experiment 1.
* **6.2 experiment2**: Task of Experiments 2a and 2b. At the start of each session, the experimenter selects the version of the task (2a or 2b).

## 🚀 How to Reproduce

To run the scripts in this repository, you will need **R** (version 4.3.1), **CmdStan** (version 2.40.0) with `cmdstanr`, and **Quarto** (version 1.7) with a LaTeX distribution. Each R script installs and loads its packages with `pacman`.

To ensure all scripts run correctly without the need to manually set working directories, simply:
1. Download or clone the entire repository.
2. Open the `VMAC_reversal.Rproj` file in RStudio.
3. Run `run_all.R`, which runs the analyses of Experiments 1, 2a, and 2b, the re-analysis of Le et al. (2025), the Bayesian model comparison, and the posterior predictive checks. Cached results in `output` are used when available, and the `force_main`, `force_comp`, and `force_reanalysis` options at the top of the script run the corresponding analyses again.
4. Run separately the power analysis (`scripts/power.R`) and the model recovery (`scripts/model_recovery.R`). The model recovery fits both models to 200 simulated datasets, so it is meant to be run on a server, with `Rscript scripts/model_recovery.R 50 8` (50 datasets per group and generating model, and 8 parallel jobs of 4 cores each). The results of each dataset are included in `output/models/recovery`, so running the script again only remakes its summary and figures.
5. Render the manuscript, the preprint, and the Supplementary Material with `quarto render vmac_reversal_manuscript.qmd`, `quarto render vmac_reversal_preprint.qmd`, and `quarto render vmac_reversal_supplementary.qmd`. The post-render step only runs on Windows, so it should be removed from `_quarto.yml` on other systems.
